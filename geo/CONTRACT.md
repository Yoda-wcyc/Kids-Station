## 2. 程度與內容規則

- **國小五、六年級**（康軒、南一、翰林社會課本的範圍）。不碰國中地理：山谷山脊、鞍部、剖面圖繪製、氣候圖判讀（雨量柱狀＋溫度折線）、洋流、板塊名稱、時區計算、經緯度換算距離、人口金字塔都不出。
- **事實要能查證**：數字、名稱、所屬縣市寫在檔頭註解「查核」那段，寫出處（政府網站、課本、維基百科條目）。不確定的就不寫。數字用課本常見的寫法（例：本島南北長約 394 公里、北回歸線約北緯 23.5 度），一律加「約」。
- 用語：臺灣用語、「臺」字（臺灣、臺北）、中國大陸（不寫「大陸」）。避開爭議的主權題（例如釣魚臺、南海主權範圍）；我國管轄只寫「臺澎金馬、東沙、太平島」。
- 不出「價值判斷」或操作建議，只考地理事實與讀圖。
- 示意圖（不是真實資料的圖）要在題目或圖上看得出是示意，不能讓小孩以為是真的統計。

## 3. 檔案結構（`geo/data/<id>.js`）

```js
/* 🌍 地理・<部分> <n>〈<標題>〉（日期）。格式見 geo/CONTRACT.md。
   內容：……（這課教什麼）
   查核：……（每個事實的出處；地點經緯度見 places.js） */
(function () {
  'use strict';
  var TW = { map: 'tw' };            // 常用的圖可以先存成變數
  Geo.add({
    id: 't2',
    learn: [ /* 3～5 張重點卡 */ ],
    practice: [ /* 剛好 30 題，第 1～10 題＝第 1 組、11～20＝第 2 組、21～30＝第 3 組；每組由易到難 */ ],
    test: [ /* 剛好 10 題 */ ]
  });
})();
```

- 檔名＝單元 id；只呼叫 `Geo.add` 一次；不准碰全域變數（包在 IIFE 裡）。
- 載入時已經有：`Geo`（引擎）、`GeoPlaces`（地點表）、`GeoMaps`（地圖）。可以用 `Geo.view(fig)`、`Geo.shapePath(shape, view)` 算座標（m2、m5 有例子）。

### 3.1 重點卡 `learn`

`{ t: '標題（≤16 字）', p: '內文（≤140 字）', fig: 圖（可省略） }`，3～5 張。重點卡免登入就能看，要把練習會用到的概念都講到。

### 3.2 題目共同欄位

| 欄位 | 說明 |
|---|---|
| `id` | `<單元>-p01`～`p30`（練習）、`<單元>-t01`～`t10`（測驗），照順序。**上線後不改**（完成紀錄、錯題都靠它）。 |
| `type` | `tap`／`drag`／`mc`／`puzzle`（見下一節） |
| `q` | 題目，≤70 字。把要做的動作講清楚（「點出…」「把…拖到…」）。 |
| `why` | 解說，≤90 字，答完一定會看到。講「為什麼」，不要只重複答案。 |
| `fig` | 圖（`tap`、`drag`、`puzzle` 必填；`mc` 可有可無） |

字數用 `Array.from(字串).length` 算（全形、半形、空白都算 1）。

### 3.3 四種題型

**`tap` 點地圖選地方**：`pins`（2～6 個圓圈）、`a`（正解的 pin id）。小孩點圓圈或按下面的號碼，再按確定。
```js
{ id: 't1-p04', type: 'tap', q: '點出臺灣本島最北端的富貴角。', fig: TW, pins: ['fuguei', 'eluanbi', 'waisan'], a: 'fuguei', why: '…' }
```

**`drag` 拖地名到地圖**：`pins`（目標圓圈，可以比地名多＝誘答位置）、`items: [{ t: '地名（≤10 字）', to: 'pin id' }]`（2～4 張，`to` 不能重複）。全部放對才算對。
```js
{ id: 't1-p10', type: 'drag', q: '把「金門」「馬祖」「澎湖」拖到地圖上對的位置。', fig: TW, pins: ['kinmen', 'matsu', 'penghu'],
  items: [{ t: '金門', to: 'kinmen' }, { t: '馬祖', to: 'matsu' }, { t: '澎湖', to: 'penghu' }], why: '…' }
```

**`mc` 選擇題配地圖**：`opts`（3～4 個，≤24 字，不重複）、`a`（正解的索引）。畫面上的選項順序由題目 id 決定（每次一樣），所以 `a` 寫 0 也可以。要考「地圖上某個地方」時用 `fig.marks` 標甲乙丙。
```js
{ id: 'm1-p28', type: 'mc', q: '地圖上的甲是金門。金門在臺灣本島的哪一方？', fig: { map: 'tw', marks: [{ p: 'kinmen', t: '甲' }] }, opts: ['西方', '東方', '南方', '北方'], a: 0, why: '…' }
```

**`puzzle` 地圖拼圖**：`pieces: [{ id, t: '名稱（≤10 字）', shape }]`（2～5 片）。每片的「原位」＝形狀所在的位置；小孩把拼圖片拖回去，全部放回自己的位置才算對。
- 預設地圖上畫每片的虛線輪廓（看形狀拼）；`outline: false` 只畫虛線圓（要靠題目提示判斷，m1-p26 例）。
- `names: false`：卡片區不寫名稱，只看形狀（較難）。
- 各片的位置（外接框中心）要相距 ≥ 40（validate 會擋）。

`shape` 的寫法：

| 寫法 | 意思 |
|---|---|
| `{ tw: 'penghu' }` | 臺灣地圖的一塊：`main` 本島、`penghu` 澎湖、`kinmen` 金門、`ludao` 綠島、`lanyu` 蘭嶼、`waisan` 外傘頂洲 |
| `{ c: 'af' }` | 一整洲：`as` 亞、`eu` 歐、`af` 非、`na` 北美、`sa` 南美、`oc` 大洋、`an` 南極 |
| `{ w: '392' }` | 一個國家（ISO 3166-1 數字代碼，字串；例 日本 392、澳洲 036、巴西 076）；加 `c: 'as'` 只取那一洲的部分 |
| `{ d: 'M10 10L50 10L30 40Z' }` | 示意圖座標的 path，**只能用絕對座標的 M、L、Z**（引擎從數字算外接框） |

### 3.4 圖 `fig`

**地圖**（經緯度自動投影，寬固定 500）：

| 欄位 | 說明 |
|---|---|
| `map` | `'tw'`（臺灣，預設範圍含金門、馬祖、澎湖、綠島、蘭嶼）或 `'world'` |
| `box` | `[西, 南, 東, 北]` 經緯度。世界圖預設全世界；**洲的單元一定要設範圍**（全世界的圖太小，圓圈會擠）。東邊可以超過 180（例 大洋洲 `[100, -50, 190, 10]`，會自動接過換日線） |
| `proj: 'polar'` | 南極為中心的圖（w7 用），`edge` 最外圈緯度（預設 -55） |
| `grid` | 經緯線：數字（度）或 `{ s: 10, lab: false }`（不標度數） |
| `lines` | `[{ lat: 23.44, t: '北回歸線', c: '#e5484d' }]`、`[{ lon: 0, t: '本初子午線' }]` |
| `names` | 要在圖上寫名字的地點 id |
| `marks` | `[{ p: 地點, t: '甲' }]`，紫色圓圈標字 |
| `hl` | 要塗成橘色的形狀（寫法同 puzzle 的 shape），例 `hl: [{ w: '392' }]` 把日本塗起來 |
| `cont: true` | 各洲塗不同顏色（世界圖） |
| `svg` | 疊在地圖上的 SVG 片段（座標＝圖上座標，可以用 `Geo.view(fig).P(經, 緯)` 算） |
| `compass: false` | 不畫指北針（預設在右下角） |
| `tw: false` | 區域圖不疊詳細的臺灣輪廓（預設：範圍東西 ≤ 60 度、而且看得到臺灣時，臺灣改畫 1:10m 詳細輪廓＋小島點） |

**示意圖**（自己畫）：`{ svg: '<rect …/>…', w: 500, h: 360, alt: '說明' }`，不寫 `map`。座標就是 SVG 座標。

### 3.5 地點 `pins`／`marks.p`

- 字串＝`places.js` 的 id（優先用這個）。
- 物件：`{ id, n: '名稱', lon, lat }`（臨時的經緯度點，例 m3 的格線交點）或 `{ id, n, x, y }`（示意圖座標）。
- `area: 1` 的地點畫大圈（一片區域，像海、國家），一般地點是小圈。
- **同一題的圓圈不能重疊**：小圈中心要相距 ≥ 68、大圈 ≥ 84（圖上座標）。太擠就放大範圍（`box`）或換地點。validate 會擋。

## 4. 題量與題型分配

- 練習剛好 **30** 題（3 組 × 10，每組由易到難，第 3 組最難）；測驗剛好 **10** 題。
- 練習裡四種題型**每種至少 2 題**；建議 tap 8～11、mc 8～11、drag 5～6、puzzle 3～4。測驗至少用 3 種題型。
- 臺灣篇每單元至少 2 題 puzzle；世界篇每洲至少 2 題 puzzle（國家或洲的形狀）。
- **選擇題的正解是「唯一最長的選項」的題數 ≤ 25%**（validate 擋）。寫完自己檢查：正解不要總是最完整、最長的那一句。
- 測驗題不要跟練習題一字不差（可以同概念、換地點或換說法）。

## 7. 地圖資料的限制（寫題前先知道）

- 來源只准 **Natural Earth（公有領域）** 或由它產生的 npm 套件（目前用 `world-atlas@2.0.2`）。**不准從其他網站下載地圖檔。**要新的輪廓（例如臺灣縣市界、主要河川）→ 回報，由負責的人擴充 `tools/build-maps.js` 重新產生，檔頭寫出處。
- `tw.js`（約 6KB）：臺灣 1:10m。**沒有**馬祖、小琉球、龜山島、彭佳嶼、東沙、太平島的輪廓（畫成 places.js 的 `islet` 小點）；沒有縣市界、河川、地形高度。
- `world.js`（約 50KB）：各國 1:110m，很簡化——小國、小島可能沒有（例如新加坡），不要出「點出新加坡的輪廓」這種題；用 `places.js` 的點就好。俄羅斯以東經 60 度切成歐、亞兩塊；法屬圭亞那歸南美洲；印尼的新幾內亞西半部、夏威夷歸大洋洲。
- 南極圖（`proj: 'polar'`）換日線的地方會有一條接縫線，不影響作答。
- t5（縣市與區域）需要縣市界，目前沒有 → 先只出用地點（縣市政府所在地）和區域（北、中、南、東）的題，縣市界等擴充後再補。
