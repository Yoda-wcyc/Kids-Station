第 4 堂：自製走路積木＋怪物血量＋打倒得錢

🎯 今天的目標

自己發明一塊「往 () 走 () 步」積木，讓史萊姆一步一步走；再讓每隻史萊姆有自己的血量，碰到塔的攻擊圈就扣血，打倒一隻得 10 元。

👀 做完你會看到：蓋好 2 座塔後，史萊姆一進塔的圈圈就閃一下、被打倒消失，金錢一隻一隻往上加（8 隻全打倒會加到 80）。
今天大約要拼 28 塊積木。
⬇️ 下載起始檔塔防_第3堂完成.sb3⬇️ 下載完成檔塔防_第4堂完成.sb3
iPad 點按鈕 → 「下載」，檔案會在「檔案」App 的「下載項目」，再到 Scratch 用「檔案 → 從你的電腦挑選」打開。完成檔是老師的解答，卡住時再用。

🧩 開始拼積木

1

做一塊自己的積木

👾 角色：怪物

點怪物角色 →「函式積木」→「建立一個積木」：

  1. 先打「往」
  2. 按「加入輸入方塊（數字或文字）」，取名 方向
  3. 再打「走」
  4. 再加一個輸入方塊，取名 步數
  5. 最後打「步」

⚠️「執行畫面不重新整理」不要勾。按確定後會出現一頂「定義」帽子。

2

教它怎麼走

👾 角色：怪物

在「定義」帽子下面接積木。方向、步數要從帽子上直接拖下來放進格子，不是自己打字。

完整腳本：怪物-走路積木（函式積木）（新增）
定義 往 (方向) 走 (步數) 步
面朝 (方向 :: custom-arg) 度
重複 (步數 :: custom-arg) 次
  移動 (2) 點
end
3

把 8 塊滑行換成新積木

👾 角色：怪物

在「走路線」裡，把 8 塊滑行拿掉，換成 8 塊 往 () 走 () 步（在「函式積木」分類裡）。方向：90 是右、180 是下、0 是上。

完整腳本：怪物-走路線（修改）
當分身產生
顯示
定位到 x:(-240) y:(130)
往 (90) 走 (35) 步 :: custom
往 (180) 走 (80) 步 :: custom
往 (90) 走 (50) 步 :: custom
往 (0) 走 (80) 步 :: custom
往 (90) 走 (50) 步 :: custom
往 (180) 走 (130) 步 :: custom
往 (90) 走 (60) 步 :: custom
往 (0) 走 (95) 步 :: custom
變數 [生命 v] 改變 (-1)
分身刪除
🔍 試試看
按綠旗，史萊姆還是照原路走到城堡嗎？大約 19 秒，跟以前差不多。如果牠「一瞬間」就到了，回去看第 1 步是不是勾了「執行畫面不重新整理」。
4

建立「血量」（只給怪物用）

👾 角色：怪物

在怪物角色裡建立變數 血量，一定要選 僅適用於當前角色！這樣每隻史萊姆都有自己的血條。

5

被塔打到就扣血

👾 角色：怪物

在怪物角色拼新的一段：

完整腳本：怪物-被打（新增）
當分身產生
變數 [血量 v] 設為 (3)
重複無限次
  如果 <碰到 [塔位 v]？> 那麼
    變數 [血量 v] 改變 (-1)
    圖像效果 [亮度 v] 設為 (60)
    等待 (0.2) 秒
    圖像效果清除
  end
  如果 <(血量) < (1)> 那麼
    變數 [金錢 v] 改變 (10)
    分身刪除
  end
end
🔍 試試看
按綠旗，馬上點兩塊空地蓋塔。史萊姆進到塔的圈圈會一閃一閃、被打倒消失嗎？金錢有沒有一直加 10？
🏆 挑戰題

只蓋 1 座塔，能打倒幾隻？把塔蓋在不同位置，哪裡打倒的最多？想想看：為什麼轉彎旁邊的塔比較厲害？

💡 這堂的觀念（用孩子聽得懂的話）

函式積木（自己做的積木）：就像幫一串動作取一個名字。以後只要說「往 90 走 35 步」，史萊姆就知道要先面朝右邊、再走 35 步。方向和步數是可以換的空格。

只限這個角色的變數：每隻史萊姆背上都有自己的小血條。打 A 只扣 A 的血，B 不會跟著扣。如果選成「所有角色」，就變成大家共用一條血，打一隻全部一起扣。

為什麼這堂要換掉滑行：第 7 堂小兵要把怪物擋下來，但「滑行」一開始就停不下來；一步一步走的話，中間就可以叫牠停。

🧯 常見卡關點和解法

卡在哪怎麼解
史萊姆一瞬間就跑到城堡建立積木時勾了「執行畫面不重新整理」。在定義帽子上長按 →「編輯」，把勾拿掉。
史萊姆原地不動或亂轉「方向」「步數」是自己打字進去的，不是從定義帽子拖下來的；要用帽子上那兩顆拖出來的圓形積木。
走到一半偏離路線8 塊的方向／步數對照講義：90/35、180/80、90/50、0/80、90/50、180/130、90/60、0/95。
打一隻，全部史萊姆一起消失「血量」建成「適用於所有角色」了。長按變數刪除，在怪物角色裡重建並選「僅適用於當前角色」。
史萊姆走到一半倒頭栽、上下顛倒旋轉方式要是「不旋轉」（起始檔已設好）。如果被改到，點怪物角色的方向設定改回「不旋轉」。
塔不會打怪「碰到」的下拉要選「塔位」；「如果 碰到塔位」要放在「重複無限次」裡面。
8 塊滑行拿不掉從第一塊滑行往下拖，會把下面整串拉走；再把「變數 生命 改變 -1」「分身刪除」接回來。

🗨️ 可以問小朋友的問題

💬 「往 90 走 35 步」裡，90 和 35 各代表什麼？
💬 如果血量是「所有角色共用」，打一隻會發生什麼事？
💬 為什麼小兵要擋怪，滑行積木就不能用了？
💬 兩座塔的圈圈重疊時，史萊姆會被扣兩倍的血嗎？（答案：不會，因為只檢查一次「碰到塔位」）
