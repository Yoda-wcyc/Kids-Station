第 7 堂：加料②：小兵擋怪互打＋兵營補兵

🎯 今天的目標

讓小兵真的上戰場：史萊姆碰到小兵就停下來互打，雙方都會扣血；小兵倒下後，兵營每 4 秒檢查一次，自動補兵（場上最多 2 隻）。

👀 做完你會看到：史萊姆走到小兵面前停住，一閃一閃被打；小兵被打倒消失，過一下兵營又派一隻補上。
今天大約要拼 24 塊積木。

iPad 點按鈕 → 「下載」，檔案會在「檔案」App 的「下載項目」，再到 Scratch 用「檔案 → 從你的電腦挑選」打開。完成檔是老師的解答，卡住時再用。

🧩 開始拼積木

1

建立兩個變數

① 小兵數：選 適用於所有角色。

② 點 小兵 角色，在小兵裡建立 血量，選 僅適用於當前角色。（它跟怪物的血量是不同的兩個變數，名字一樣沒關係。）

2

舞台開場：小兵數歸零

🖼️ 角色：舞台

在「場上怪物 設為 0」下面補一塊 變數 小兵數 設為 0。

完整腳本：舞台-開場與失敗（修改）
當綠旗被點擊
背景換成 [草地 v]
變數 [金錢 v] 設為 (100)
變數 [生命 v] 設為 (10)
變數 [波次 v] 設為 (0)
變數 [場上怪物 v] 設為 (0)
變數 [小兵數 v] 設為 (0)
等待直到 <(生命) < (1)>
背景換成 [失敗 v]
停止 [這個物件的其它程式 v]
廣播訊息 [遊戲結束 v]
播放音效 [失敗 v] 直到結束
停止 [全部 v]
3

兵營自動補兵

⛺ 角色：兵營

把「否則」裡的「建立 小兵 的分身」和「播放音效 派兵」拿掉，換成「重複無限次」這一段：每 4 秒看一次，小兵數不到 2 就派一隻。

完整腳本：兵營-點一下蓋兵營（修改）
當角色被點擊
如果 <(造型 [名稱 v]) = [空營地]> 那麼
  如果 <(金錢) < (70)> 那麼
    說出 [錢不夠！] 持續 (1) 秒
  否則
    造型換成 [兵營 v]
    變數 [金錢 v] 改變 (-70)
    重複無限次
      如果 <(小兵數) < (2)> 那麼
        建立 [小兵 v] 的分身
        變數 [小兵數 v] 改變 (1)
        播放音效 [派兵 v]
      end
      等待 (4) 秒
    end
  end
end
4

小兵有血量、會打怪

🛡️ 角色：小兵

在「小兵-出動」最上面加 血量 設為 4，最下面接「重複無限次」互打那一段：

完整腳本：小兵-出動（修改）
當分身產生
變數 [血量 v] 設為 (4)
顯示
滑行 (1) 秒到 x:(30) y:(隨機取數 (35) 到 (65))
重複無限次
  如果 <碰到 [怪物 v]？> 那麼
    變數 [血量 v] 改變 (-1)
    等待 (0.5) 秒
  end
  如果 <(血量) < (1)> 那麼
    變數 [小兵數 v] 改變 (-1)
    分身刪除
  end
end
🔍 試試看
按綠旗 → 開始 → 蓋兵營：場上最多 2 隻小兵嗎？小兵被史萊姆碰到會扣血、倒下消失，然後兵營再補一隻嗎？
5

史萊姆被小兵擋住

👾 角色：怪物

回到怪物的「定義 往 () 走 () 步」，在「重複」裡面、「移動 2 點」上面插入 等待直到 <<碰到 小兵> 不成立>。

完整腳本：怪物-走路積木（函式積木）（修改）
定義 往 (方向) 走 (步數) 步
面朝 (方向 :: custom-arg) 度
重複 (步數 :: custom-arg) 次
  等待直到 <<碰到 [小兵 v]？> 不成立>
  移動 (2) 點
end
6

史萊姆碰到小兵也扣血

👾 角色：怪物

在怪物「被打」裡，把「如果 碰到 塔位」的條件換成 <碰到 塔位> 或 <碰到 小兵>（「或」在「運算」分類）。

完整腳本：怪物-被打（修改）
當分身產生
變數 [血量 v] 設為 ((波次) * (10))
重複無限次
  如果 <<碰到 [塔位 v]？> 或 <碰到 [小兵 v]？>> 那麼
    變數 [血量 v] 改變 (-1)
    圖像效果 [亮度 v] 設為 (60)
    等待 (0.2) 秒
    圖像效果清除
  end
  如果 <(血量) < (1)> 那麼
    變數 [金錢 v] 改變 (10)
    變數 [場上怪物 v] 改變 (-1)
    播放音效 [打倒 v]
    分身刪除
  end
end
7

結束時兵營別再派兵

⛺ 角色：兵營

在兵營「遊戲結束」那段的「隱藏」下面加 停止 這個物件的其它程式，讓派兵迴圈停下，播結束音效時就不會再冒出新小兵。

完整腳本：兵營-遊戲結束（修改）
當收到訊息 [遊戲結束 v]
隱藏
停止 [這個物件的其它程式 v]

玩一整場：

  • 雙方都一閃一閃扣血嗎？

💡 這堂的觀念（用孩子聽得懂的話）

兩個同名的「血量」：怪物有一條、小兵有一條，都是「只限這個角色」。就像每個班都有「班長」，A 班班長跟 B 班班長是不同人。

等待直到…不成立：史萊姆每走一步前先看：「我有沒有碰到小兵？」有就停下來等，等到沒碰到（小兵被打倒）才繼續走。這就是第 4 堂改成一步一步走的原因。

小兵數＝兵營的點名簿：派一隻 +1、倒一隻 −1，兵營每 4 秒看一次，少於 2 隻才補。

🧯 常見卡關點和解法

卡在哪怎麼解
小兵一直生、超過 2 隻小兵的「血量 < 1」裡漏了「小兵數 改變 -1」，或兵營沒寫「小兵數 < 2」；另外舞台開場要「小兵數 設為 0」。
重玩一局兵營都不派兵舞台開場漏了「變數 小兵數 設為 0」，上一局留下的小兵數還是 2。
史萊姆穿過小兵不停「等待直到 碰到小兵 不成立」要放在「重複」裡面、「移動 2 點」上面（每走一步都檢查），而且是改在函式積木的「定義」那段。
打一個小兵，兩個小兵一起消失小兵的「血量」選成「適用於所有角色」或建在別的角色。要在小兵角色裡建，選「僅適用於當前角色」。
小兵不會打怪、史萊姆不扣血怪物「被打」的條件要換成「碰到 塔位 或 碰到 小兵」。
結束畫面又冒出一隻小兵兵營「遊戲結束」漏了「停止 這個物件的其它程式」。
時間不夠步驟 6（史萊姆被小兵扣血）可以最後做：小兵仍然會擋怪、會被打死，只是不會打怪。
