4

點一下蓋塔

🏰 角色：塔位

在塔位角色拼新的一段。重點：

  • 造型編號小於 3 ＝ 還是空地，才能蓋。
  • 「錢不夠！」的驚嘆號是全形的。
  • 「造型換成」的格子裡放一個「+」運算：造型編號 + 2。
完整腳本：塔位-點一下蓋塔（新增）
當角色被點擊
如果 <(造型 [編號 v]) < (3)> 那麼
  如果 <(金錢) < (50)> 那麼
    說出 [錢不夠！] 持續 (1) 秒
  否則
    造型換成 ((造型 [編號 v]) + (2))
    變數 [金錢 v] 改變 (-50)
    圖層移到 [最下 v] 層
  end
end

💡 這堂的觀念（用孩子聽得懂的話）

造型編號：塔位有 4 個造型，照順序是 1 高台空地、2 低地空地、3 高台塔、4 低地塔。所以「編號 + 2」剛好把空地變成同一種地形的塔，一塊積木就搞定兩種地形。

如果…否則：錢不夠就說話，不然（否則）就蓋塔。Scratch 只有「小於」，所以寫成「金錢 < 50 就說錢不夠，否則蓋塔」。

分身會留在原地：本尊走到一個位置複製一次，影印本就留在那裡；本尊再走去下一個位置。

🧯 常見卡關點和解法

卡在哪怎麼解
塔蓋出來是錯的地形（高台蓋成低地塔）到「造型」分頁確認順序是 1 高台空地、2 低地空地、3 高台塔、4 低地塔，不要拖動造型順序。
只有 5 塊空地最後一塊是本尊自己站：最後一塊「定位到 x:-215 y:60」不要再接「建立分身」，但也不能漏掉。
點了一直說錢不夠，或錢變負的外層「如果 造型編號 < 3」和內層「如果 金錢 < 50」要分清楚；「說出」放在「那麼」，換造型和扣錢放在「否則」。
「造型 編號」積木找不到在「外觀」最下面；放進格子後，下拉選單要選「編號」不是「名稱」。
蓋好塔後，旁邊的空地點不到漏了「圖層移到最下層」：塔的大圓圈蓋在旁邊空地上，會搶走手指的點擊。
驚嘆號打成半形講義寫全形「！」。半形也能跑，但為了跟完成檔一樣，請用全形（中文輸入法下打）。
