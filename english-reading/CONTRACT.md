# 英文閱讀測驗：寫題契約（CONTRACT）

> 給 5 位作者。你只要看這一份＋`data/s0.js` 的 10 篇樣本。寫完一定要跑 `node english-reading/check.js a<你的號碼>`，看到「✓ 全部通過」才算交稿。
> 讀者是**國小五年級**的孩子，用 iPad 看。文章要短、要好懂、要有趣。

## 1. 你要交什麼

- **只改你自己的檔**：`english-reading/data/a1.js`～`a5.js`（作者 1 改 a1.js，依此類推）。不要動別的檔、不要動 `s0.js`、不要改程式。
- 每人 **38 篇**，篇號和主題見 §8。篇號是固定的，不要自己換。
- 檔案存成 **UTF-8、不帶 BOM**。

## 2. 資料格式

檔案開頭已經寫好，把文章加在 `concat([` 和 `])` 中間，一篇一個物件，用逗號隔開：

```js
window.DATA_ER = (window.DATA_ER || []).concat([
  { id: 'e005', lv: 1, genre: 'story', topic: 'school', title: 'The Lost Eraser', zh: '不見的橡皮擦',
    gloss: { picnic: '野餐' },            // 選填：字表外的字＋中文（最多 3 個）
    names: ['Mimi'],                      // 選填：名單外的人名、地名、寵物名（最多 6 個）
    body: [
      ['Ben is in the classroom.', 'He wants to draw a cat.'],   // 一段＝句子陣列，一個字串只放一句
      { who: 'Amy', s: ['Can I help you?', 'I have two erasers.'] }, // 對話：誰說的＋說了哪幾句
      { h: 'Bus Times' },                                         // 小標題（告示、時刻表、信的稱呼和署名）
      { table: [['Bus', 'Time'], ['No. 1', '8:30 a.m.'], ['No. 2', '9:00 a.m.']] }  // 表格：第一列是表頭，至少 2 列資料
    ],
    qs: [
      { id: 'q1', k: 'detail', q: 'Where is the eraser?', opts: ["On Ben's ear", "In Ben's bag", 'Under the desk', "In Mia's hand"], a: 0,
        why: '文章最後說：小橡皮擦就在班的耳朵上。', ev: ['The small eraser is on his ear!'] }
    ] },
]);
```

| 欄位 | 規則 |
|---|---|
| `id` | 見 §3 |
| `lv` | 1＝易、2＝中、3＝難（要跟 id 開頭字母一致） |
| `genre` | 文體，只能用：`story` 故事、`diary` 日記、`letter` 信件／email、`notice` 告示／海報、`dialogue` 對話、`schedule` 時刻表／行程表、`info` 說明／科學小知識、`howto` 步驟 |
| `topic` | 主題，只能用你自己的 4 個（§8） |
| `title` | 英文標題，1～8 個字，也要過字表 |
| `zh` | 中文標題 |
| `body` | 文章。只能用上面四種區塊 |
| `qs` | 題目，見 §6 |

- **一個字串只放一句**，用 `.`、`!`、`?` 結尾（朗讀一句一句念、答案依據一句一句標，靠的就是這個）。`Mr. Lin`、`7:30 a.m.` 這種縮寫不算斷句。
- 引號裡的話可以放在同一句：`'His teacher said, "Winning is nice, but not giving up is better."'`

## 3. id 規則

- 易 `e` ＋三位數、中 `m` ＋三位數、難 `h` ＋三位數，例如 `e005`、`m017`、`h041`。
- 只能用 §8 分給你的號碼，每個號碼都要用到、不能重複。
- 題目 id 照順序 `q1`、`q2`、`q3`、`q4`。
- 上線後 id 不改（錯題庫靠它找回原題）。

## 4. 字數與句長

| 級 | 字數（只算 body，標題、題目不算） | 每句最多 | 題數 |
|---|---|---|---|
| 易 A1 | 40～70 | 12 字 | 3 |
| 中 A1+ | 60～100 | 15 字 | 3 或 4 |
| 難 A2 | 90～140 | 20 字 | 4 |

- 字數照英檢的算法：英文字、數字各算一個（`7:30`、`a.m.`、`black-faced` 各算一個）。表格每格、小標題都算。
- 易：多用現在式、短句、常見主詞（I、he、we）。中：可以用過去式、and／but／because。難：可以用 when／if 子句、比較級、簡單的被動，但不要超過國中。

## 5. 用字（字表檢查）

| 級 | 可以用的字 |
|---|---|
| 易 | 站上單字 lv1、lv2（`data/words*.js`）＋基本功能詞（代名詞、冠詞、介系詞、連接詞、be／do／have、can／will…、數字） |
| 中 | 易的全部＋lv3 |
| 難 | 中的全部＋教育部國中小 2000 字＋CEFR-J A1～A2。**B1 以上的字都算表外**（最高 A2） |

- 變化形自動認：複數、三單、過去式、-ing、比較級、-ly（plays、played、bigger、quickly）。不規則變化（went、children）也認得。
- **字表外的字每篇最多 3 個，每個都要寫在 `gloss`**：key 寫一個英文字，文章裡至少要有一處**一模一樣**（不分大小寫）；同一個字的複數、過去式也算被註解到（key `spoonbill`，文章有 spoonbill 也有 Spoonbills 都可以）。value 是中文（最多 12 個字）。畫面會在字下面加點點底線、文章下面列「📌 生字」。
- 題目和選項**不能用表外字**（除非那個字已經在這篇的 gloss 裡）。題目可以多用這些說法：paragraph、mainly、main idea、probably、true、according to、sentence、line、mean、story、article、notice、letter、email、title、best、writer、reason。
- 人名、地名：`gept/vocab/names.js` 名單裡的直接用（Amy、Ben、Mr. Lin、Taipei、Tainan…）。名單外的（寵物名、自編店名）寫進 `names`，最多 6 個。**不准用真人名字**（名人、網紅、政治人物）。
- 不確定某個字可不可以用：跑 `node english-reading/check.js a<號碼> --words`，會列出每篇的表外字。

## 6. 題目

### 6.1 五種題型

| `k` | 中文 | 問什麼 | 題目範例 |
|---|---|---|---|
| `main` | 主旨 | 整篇在說什麼、最好的標題、作者為什麼寫 | What is the story mainly about? ／ What is the best title? |
| `detail` | 細節 | 文章裡直接寫的：誰、什麼、哪裡、幾點、多少 | When will the class meet? |
| `infer` | 推論 | 文章沒有直接寫、要想一下：為什麼、心情、接下來 | How does Lily probably feel? |
| `vocab` | 字義 | 某個字在這裡的意思（選項可以用中文） | What does "together" mean here? |
| `ref` | 指代 | it／they／he／there… 指的是誰或什麼 | In paragraph 2, what does "it" mean? |

### 6.2 每篇的規則（check.js 會擋）

- 每篇至少 1 題 `detail`；同一種題型最多 2 題。
- 易的 `infer` 最多 1 題；難一定要有 `main` 或 `infer`。
- `vocab`：題目裡用引號標出那個字（`"busy"`），`ev` 那句要有這個字。
- `ref`：題目裡用引號標出代名詞，只能是 it、its、they、them、their、he、him、his、she、her、we、us、our、this、that、these、those、there、one；`ev` 那句要有這個字。

### 6.3 全部題目的配比（你的 38 篇合起來，check.js 會算）

| 主旨 | 細節 | 推論 | 字義 | 指代 |
|---|---|---|---|---|
| 15～25% | 30～45% | 10～25% | 10～20% | 10～20% |

大約的配法：38 篇約 130 題 → 主旨 26、細節 48、推論 20、字義 18、指代 18。

### 6.4 選項

- 剛好 **4 個**、不能重複（不分大小寫、標點）。選項要**全部英文或全部中文**（字義題常用中文）。
- `a`＝正確答案是第幾個（0～3）。畫面會打亂順序，所以 `a` 寫 0 沒關係。
- 錯的選項要「看起來有道理」：用文章裡出現過的東西、相近的時間或數字，不要放一看就知道錯的。
- 正確答案**不要老是最長**的那個（全部題目裡最多一半，check.js 會算）。
- 不要「以上皆是／以上皆非」，不要兩個選項意思一樣。

### 6.5 解說 `why`（中文）

- 6～150 字，**用孩子看得懂的話**說「為什麼是這個答案」：先指出文章哪裡寫了，再說怎麼想到的。
- 推論題要寫出推的那一步（「她想做卡片、還請奶奶告訴貓她要來了 → 很期待」）。
- 指代題寫出「它／他們」指的是誰，以及是哪一句提到的。
- 同一篇裡每題的解說不能一樣。不要寫「答案是 A」（選項會打亂）。

### 6.6 答案依據 `ev`

- 1～2 段文字，**從文章照抄**（大小寫、標點一樣），每一段只能對到文章裡的一句（或表格的一列）。畫面會把那句標成綠色。
- 抄一小段就好（例如 `'at about two in the afternoon'`），只要它在全文只出現在一句裡。
- 主旨題也要給：放最能代表主旨的那一句。

## 7. 檢查工具

```
node english-reading/check.js a3            只看你的檔（撞文還是會跟全部的篇比）
node english-reading/check.js a3 --words    另外列出每篇的表外字
node english-reading/check.js --final       交稿總檢查（整合人跑：每人 38 篇到齊、每種文體 ≥ 3 篇、全部 200 篇）
```

檢查：格式、id 唯一、篇號和主題是不是你的、字數、句長、一個字串一句、表外字 ≤ 3 而且都有 gloss、題目沒有表外字、專有名詞、4 個不重複的選項、正解索引、中文解說、ev 對得到一句、題型規則、配比、正解最長的比例、**跟所有其他篇（含樣本、別的作者）撞文或過度相似**（同一句 ≥ 7 字一樣，或 5 字連續片段重疊 ≥ 30%，或標題一樣）。
有錯會列出「✗ a3.js e036：…」，照著改到全部通過。`⚠` 是提醒，可以不改。

## 9. 內容規則

- **全部原創**。不准抄或改寫任何教材、課本、考古題、英檢題、網路文章、繪本；也不要跟 `gept/data/` 的題目雷同。
- 事實（科學、台灣地理、動物）要正確、用保守的說法（「大約」、「很多」），不寫不確定的數字。
- 內容正向、安全：不寫暴力、恐怖、危險動作（如果出現，要有「請大人幫忙」）、不寫品牌名、不寫真人。
- **不准寫任何真實小孩的個資**：真名、學校、班級、住址、照片描述都不行。人名只用名單裡的常見英文名。
- 台灣用語：中文解說、中文標題、gloss 用台灣用語（捷運、腳踏車、便當）。
- 時間、金額寫法：`7:30 a.m.`、`NT$50`（朗讀會念成 50 NT dollars）。

## 10. 禁止事項

- ✗ 改別人的檔、改 `s0.js`、改任何 `.js` 程式、改 `check.js` 讓自己過關
- ✗ 用不是你的篇號或主題
- ✗ 超出字數、句子太長、一個字串塞兩句
- ✗ 表外字超過 3 個、沒寫 gloss、題目用表外字、用 B1 以上的字
- ✗ 解說寫英文、寫「答案是 A」、空白
- ✗ 抄襲、改寫現成教材或考古題、跟其他篇太像
- ✗ 真人名字、品牌、任何小孩的個資
- ✗ 檔案帶 BOM、用 Big5 存
