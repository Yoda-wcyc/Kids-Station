# 小朋友學習站（repo：Kids-Station）

給國小孩子（iPad Safari 優先）的多科目學習網站。純 HTML/CSS/JS，不用安裝。瀏覽內容可離線（直接開 `index.html` 也能看），登入與練習需要連網（練習與遊戲要先登入會員）。

## 科目

```
頂端科目列（subjects.js / subjects.css，記住上次的科目：ke_settings.subject）
├─ 國語   #s/chinese   活動卡片（2026-11-01）
│    └─ 閱讀素養 100 篇  #s/chinese/reading → iframe 開 chinese/reading.html（L1～L4 循序解鎖；規格 kids-member/docs/CHINESE_READING_SPEC.md；node test/chinese-reading.test.js）
├─ 數學   #s/math      活動卡片
│    └─ 天平解方程式  #s/math/balance → iframe 開 math/balance.html
├─ 社會   #s/social    心智圖，每單元一張卡（單元一～四）
│    └─ #s/social/u1 … → iframe 開 mindmap/social.html?u=u1
├─ 自然   #s/science   心智圖，每單元一張卡（太陽與光、植物世界、水溶液、力與運動）
│    └─ #s/science/n1 … → iframe 開 mindmap/science.html?u=n1
├─ 英文   #home 等原本路由（app.js，預設科目）
├─ AI     #s/ai        活動卡片
│    ├─ AI 會唬爛     #s/ai/hallucinate → ai/hallucinate.html
│    ├─ 怎麼問得好    #s/ai/ask-well    → ai/ask-well.html
│    └─ 秘密不能說    #s/ai/secrets     → ai/secrets.html
└─ 遊戲   #s/game      活動卡片
     └─ Scratch 塔防（7 堂課） #s/game/scratch-td → game/scratch-td/web/index.html
```

活動卡片定義在 `subjects.js` 的 `ACTS`（新增活動＝加一筆 `{id,title,desc,icon,src}`）。點卡片後頁面用 iframe 開在科目列下方，上面有「← 回某科」。
社會、自然的單元卡由 `subjects.js` 的 `MM_UNITS` 產生（id、標題要跟 `mindmap/data` 一致）；心智圖的資料格式與抽題規則見 `mindmap/data/FORMAT.md`。

紀錄存在瀏覽器 localStorage：`ke_progress`、`ke_mistakes`、`ke_settings`、`ke_log`、`ke_learned`、`ke_correct`、`ke_agg`（壓縮過的舊紀錄）；配對資訊 `ke_sync`（只在這台）。家長頁可以匯出／匯入 JSON 備份（含學會紀錄）。

「學會了」：每個學習項目有一組固定題目，**每一題都答對過一次**才能按「👍 學會了」（沒完成前是灰色 🔒「還差 N 題」）。

| 項目 | 題組（打字題一律排最後） |
|---|---|
| 單字 | 7 題：聽音選字、看中文選英文、🎤，＋打字：填空拼字 2 題、看中文打字、例句中翻英（看中文例句打出句中這個字；例句用不了的 as／do／hide／bless 改「中文＋詞性＋第一個字母」）。a、I 沒有填空，改聽寫拼字 |
| 片語 | 9 題：聽音選、看中文選、看英文選、例句填空、🎤，＋打字：中翻英打字、例句填空打字、聽寫片語、例句中翻英（看例句中文打整句；超過 10 個字只打含片語的那半句，逗號可省） |
| 字根 | 1＋n＋max(n,3)＋2 題：意思、用字根組單字、字根拼字（打字），＋2 題中翻英（看中文打出含這個字根的例字） |
| 文法 | 15 題：10 題選擇（2 題換 🎤）＋5 題打字（2 題中翻英 `typed`＋填空／改錯打字） |
| 句型 | 15 題：10 題重組／看中文選句子（2 題換 🎤）＋5 題中翻英打字（`typed`＋加練句）。共 105 個 |

- 卡片上有「練習 6/15 ✓」進度條和「🎯 練習這組」：只出還沒答對過的題，打字題最後；答錯會排回後面（「再一次！」）直到答對，中途離開進度照樣保留。
- 一般「練習」頁答對的題目也算（同一個題號）；以前答對過的會從作答紀錄追溯（`ke_log`），另存在 `ke_correct` 避免舊紀錄被截掉。
- 題組完成後「學會了」才解鎖；按下去還要**通過小測驗**才標記（不含開口說）：單字 3 題（聽音選字、看中文選英文、聽寫拼字）全對；字根 3 題（意思＋2 個衍生字）全對；文法從該主題隨機 5 題、答對 4 題；句型 3 題（2 題重組＋1 題看中文選句子）全對。沒過顯示錯題（照常進錯題庫），可「再試一次」或「回去複習」；小測驗答錯不會讓題組重新上鎖。
- 通過才記錄時間與小測驗分數（`ke_learned` = `{itemId: {at, score:"4/5"}}`，畫面顯示台北時間），可按「取消」移除。學習頁可篩選 全部／已學會／未學會／可以按學會了；家長頁「學會紀錄」表有分數欄（舊紀錄顯示「—」）。itemId 例：`word:apple`、`root:un`、`grammar:be`、`pattern:lets`。
- 打字題判分：不分大小寫、空白合併、句尾 .!? 不計、彎引號視同直引號；`typed` 可加 `alts`（例如 `["I'm a student."]`）接受其他正確寫法。答錯會標出第一個不一樣的字。
- **打字保底（2026-10-25）**：練習這組、「學會了」小測驗、📘 課本專屬練習與考試、一般練習回合，每一回都至少 3 題打字、其中至少 2 題中翻英，打字排最後（考試照段考六大題順序，不移）。小測驗：單字／片語／字根／句型 3 題全打字、全對；文法 5 題（打字 3、中翻英 2）、對 4 題。一般練習（練習設定、各頁 🎯、錯題庫、例題庫、結果頁再練）由 `E.round()` 抽題後 `withTyped()` 從後面把選擇題換成同一批項目的打字題，總題數不變；一回不到 3 題就全用打字。單字頁「🎤 說說看」不加。
- **🎤 口語對話考試（2026-11-01，五上～六下每兩課一份，共 8 份 × 100 題）**：題庫 `data/oral.js`（`window.DATA_ORALS`；每份難度 1／2／3＝40／40／20，掛在兩課的 `u.oral`）；入口在各課的 📝 考試分頁。一次 `E.tbOral()` 抽 20 題（難度 1×8 → 2×8 → 3×4，由易到難），TTS 唸考官的話、畫面只給中文提示；判分沿用 🎤 的 `speakGrade`（mode `keys`：評分重點都說到就對；開放欄 ___ 用類別關鍵字「任一個星期／地點／數字…」，只說關鍵答案也對），每題可重講 3 次、跳過算錯；錯題進英文錯題庫、送 `english:test`；**不算單元完成**。純口語，**不套打字保底**（smoke 裡明確排除並反向斷言）。檢查：`node test/oral.test.js`（題數、用字範圍、判分）；紙本考卷由 `考卷\gen_oral.js [key]` 產生（只留本機）。
- **六上、六下課本（2026-11-01，hanlin-7-*、hanlin-8-*）**：依屏東縣某國小 114 學年度「六年級英語 Here We Go 7／8」公開教學計畫整理各課單字與句型（計畫沒有日常用語、對話），全部標「待課本核對」。課本專屬題：`tbBlanks` 先換空格家族再放寬，全部單元同一輪不重複同一句（smoke 每課都檢查）。


## 裝置同步（iPad ↔ 電腦）

家長頁「☁️ 裝置同步」：第一台按「產生同步碼」（像 `ABCD-EFGH`），另一台輸入同一組碼或打開同步連結（`https://yoda-wcyc.github.io/Kids-Station/#sync=ABCD-EFGH`），兩台的紀錄就自動合在一起。不用帳號。

- **會同步**：作答紀錄（`ke_log`）、學會紀錄（`ke_learned`）、錯題庫（`ke_mistakes`）。題組進度、能不能按「學會了」都從合併後的作答紀錄算，所以也會一起同步。語音速度等設定**不**同步。
- **其他科（文件 v3，2026-10-09）**：英文星星／完成回數（`ke_progress`，每台各記自己的、總數＝加總）、社會／自然心智圖過關與複習（`kids_mm_progress`）、挖空／背架構加權（`kids_mm_blanks`）、數學天平題目清單（`tianping-eq-list-v2`，聯集＋刪除墓碑，最多 30 題；清單狀態另存 `ke_sync_eq`）、Scratch「我完成了」（`kids_scratch_done`）；2026-10-20 文件 v5 加單元完成紀錄（`kids_done`）。不同步：登入（`kids_jwt` 等）、學習幣（`kids_coin_*`）、設定（`ke_settings`、`kids_mm_ui`、`ks_parent_pin`）、遊戲存檔（`hi_*`、`hw_*`）。心智圖、天平在首頁 iframe 裡時借用首頁的同步；合併規則細節見 `syncmerge.js` 檔頭。舊版頁面讀到 v3 文件不會壞（只認得英文欄位），新版下次同步會從本機補回其他欄位。
- **什麼時候（2026-10-19 起自動即時同步，計時零件在 `syncauto.js`）**：
  - 上傳：任何紀錄變動（作答、學會了／取消、錯題增減、心智圖過關與挖空、天平題目、Scratch 完成；別的分頁或子框寫進同步範圍也算）後 1.5 秒內沒有新變動就送，最晚 3 秒一定送；做完一回合、按學會了馬上送。先拿上次跟伺服器對到的版本合併直接 PUT（If-Match），被別台先改過（412）才 GET、合併再 PUT，最多重試 3 次。頁面藏起來／關掉（visibilitychange、pagehide）立刻送一次（PUT 用 fetch keepalive）。
  - 下載：有同步碼、頁面看得到時每 20 秒問一次（`GET ?since=<ETag>`，伺服器沒變回 204、不合併）；回到前景、focus、重新連上網路立刻問；頁面藏起來就停。連續失敗 40 秒、80 秒、最多 2 分鐘再試。
  - 畫面：合併到新資料發 `kids-sync-updated`（首頁＋同網域子框），英文清單／學會徽章、錯題數、心智圖關卡與單元卡、天平題目清單、帳號頁同步卡各自重畫；作答中（`KESync.hold`）先扣著，這一輪結束才發。
  - 頁角小雲朵（登入小元件旁）：☁️ 已同步・剛剛／x 分鐘前、⏳ 上傳中、📴 離線（恢復後自動補傳），點一下看最後同步時間。帳號頁「立刻上傳並同步」保留當備用。

## 新增單字（含課本單字）

在 `data/words.js` 的陣列裡加一行（記得前一行結尾要有逗號）：

```js
{w:"pumpkin",ipa:"/ˈpʌmpkɪn/",pos:"n",zh:"南瓜",lv:2,tags:["food"],ex:"We make pumpkin soup.",exZh:"我們煮南瓜湯。",src:"textbook-4A-L3"},
```

- `src`：來源。教育部字彙是 `"moe"`；課本單字用 `"textbook-4A-L3"`（冊別-課次）。只要出現第二種來源，單字卡頁和練習頁就會出現「來源」篩選。
- `tags` 第一個是主題：animal food color number family school body weather place time verb adj（也可以自訂新的英文 tag，會直接顯示英文）。
- `zh` 不可以和別的字完全相同（避免選擇題出現兩個一樣的中文）。
- 改完跑 `node test/smoke.js`，看到 `OK` 就好。

文法題：`fill` 的答案 `a` 一定要在 `opts`（4 個不重複）裡；`fix` 給 `wrong`、`right`、`why`。字根的 `parts` 合起來要等於單字。
